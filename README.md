# codsoft_tasks

1. Task 1 — Data Cleaning & Preprocessing
This project focuses on cleaning and preprocessing raw datasets using Python, Pandas, and NumPy. It involves identifying missing values, handling null entries, removing duplicate records, correcting inconsistent data, and converting data types. The cleaned dataset is saved as a new CSV file for further analysis.


Branch Name: task-1-data-cleaning-preprocessing


2. Task 2 — Exploratory Data Analysis (EDA)
This project performs Exploratory Data Analysis (EDA) using Python, Pandas, NumPy, Matplotlib, and Seaborn. It examines dataset features through descriptive statistics, identifies trends and distributions, explores relationships between variables, detects outliers, and generates meaningful insights to support business decisions.


Branch Name: task-2-exploratory-data-analysis


3. Task 3 — Data Visualization Dashboard
This project presents data insights through visualizations created using Python, Matplotlib, Seaborn, and Plotly. It includes bar charts, line charts, pie charts, histograms, and scatter plots with clear titles, labels, legends, and colors. The visualizations help identify trends, compare data, and communicate findings effectively. An interactive dashboard can also be developed using Power BI or Tableau.




Branch Name: task-3-data-visualization-dashboard


4. Task 4 — Customer Data Analysis
This project analyzes customer information using Python, Pandas, NumPy, Matplotlib, and Seaborn to understand purchasing behavior. It segments customers based on age, location, and buying patterns, identifies valuable customer groups, and presents insights through visual reports. The analysis also suggests data-driven marketing strategies to improve customer engagement and business performance.


Branch Name: task-4-customer-data-analysis
